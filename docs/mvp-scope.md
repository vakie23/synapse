# MVP Scope

## Customer Journeys
1. Browse electric equipment by category and search.
2. View product details with pricing, stock, and safety notes.
3. Add products to cart and edit quantities.
4. Checkout with delivery address and preferred payment method.
5. Receive order confirmation and track order status.

## Product Categories
- Wiring and cables
- Circuit breakers and protection
- Lighting and bulbs
- Switches and sockets
- Power tools
- Test and measurement devices
- Solar and backup power
- Installation accessories

## Accessibility Requirements
- Keyboard-first navigation for all interactions.
- Form labels and error messages announced to screen readers.
- Strong color contrast and visible focus indicators.
- Large touch targets for mobile use.

## Nationwide Delivery Rules
- All regions can place orders if postcode is valid.
- Delivery fee is computed from region plus order weight band.
- Estimated delivery window is shown before checkout confirmation.
- Cash on delivery can be disabled for high-risk zones.
